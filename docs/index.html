skillforge

Build a skill once. Install it into any AI agent with one command.

Claude Code Claude Desktop Cursor Any MCP Agent

Install

$ brew install ZenMicro-Tech/tap/skillforge

One binary, four interfaces

A skill compiles to a single binary that works as an MCP tool, CLI command, HTTP server, or library.

Zero config agent registration

skillforge add detects your agents and registers the skill automatically.

OCI distribution

Publish to any OCI registry. Others install with a single reference — no cloning, no building.

Mux mode

Aggregate all installed skills into a single MCP server. New skills appear without restarting agents.

Get started in 60 seconds

1

Scaffold a new skill

$ skillforge new word-count
2

Build and install into all detected agents

$ skillforge add word-count
3

Open Claude Code — your skill is ready to use

$ claude
> Count the words in my last commit message

What's a skill?

A self-contained directory with a prompt, schema, and implementation that compiles into a portable binary:

my-skill/ skill.toml # metadata and interfaces prompt.md # LLM-facing instructions schema.json # JSON Schema for tool input src/main.rs # your logic
